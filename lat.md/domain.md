# Domain

QAI PageLM language and authority boundaries are defined in
[CONTEXT.md](../CONTEXT.md); this page is an entry map rather than a duplicate
glossary.

## Users and scope

Human users, integration users, QAI integration exceptions, and unclassified
users are separate types. PageLM Learning Scope defines what admitted material
can participate in learning.

## Materials

Shared Library, Learning Material, and Personal Chat Material have different
visibility and ownership. Personal Learning State and PageLM Learning User bind
learning behavior to the authorized user.

## Derived artifacts

Learning Derivatives remain tied to admitted material, access scope, and source
revision. Resolve exact terms in `CONTEXT.md` before changing migration,
retrieval, or authorization behavior.
