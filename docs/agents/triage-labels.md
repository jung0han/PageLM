# Triage Labels

The engineering skills use five canonical triage roles. This repository maps them directly to Linear labels.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an implementation agent |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, use the matching Linear label. Edit the right-hand mapping if the workspace vocabulary changes.
